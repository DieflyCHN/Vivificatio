# Vivificatio
An Experimental Digital Evolution System

> Ex regulis, vita.
> 
> 从规则中，生命诞生。
>
> D. de Vliegh

Vivificatio 是一个实验性的数字演化系统。个体（Anima）通过无性复制产生后代，基因突变、功能区表达、端粒长度和寿命共同决定谱系能否延续。每个 Cosmos 从一个创始个体开始，运行到种群灭绝或触及人口上限。

## 运行

需要 Python 3.10 或更新版本，仅使用标准库。在仓库根目录运行：

```bash
# 默认模拟 100 个 Cosmos
python vivificatio/main.py

# 指定轮数和随机种子
python vivificatio/main.py --rounds 100 --seed 42

# 调试模式：输出出生、死亡和功能区序列
python vivificatio/main.py -r 1 -s 42 -v
```

`-r` / `--rounds` 设置实验次数，`-s` / `--seed` 设置随机种子。未指定种子时，程序会生成并打印一个种子。在相同代码、参数和 Python 环境下，使用相同种子与轮数可复现实验。

调试模式每个模拟时间步暂停 0.5 秒。按 Ctrl+C 可停止实验，并汇总已经完成的 Cosmos；正在运行的 Cosmos 不计入统计。

## 当前规则

### 个体与基因组

每个个体记录自己的 UID、亲代 UID 和世代。创始个体为第 1 代，子代世代为亲代加 1。

初始基因组为：

```text
tel_l      start   functional   stop   tel_r
UYZUYZUYZ  SSS     CCCCCCCCCC   EEE    UYZUYZUYZ
```

当前起始区和终止区只是保留的基因组结构，不参与繁殖判断。

个体寿命为 10 个模拟时间步，每步最多产生一个子代。新生儿从下一步开始行动。寿命限制作用于单个个体，不是整个谱系的世代上限。

### 表达与繁殖

功能区从左到右，第 `n` 个字符的表达权重为：

```text
w(n) = 0.75 + 0.25 × 0.5^n，n 从 0 开始
```

同一字符的权重相加，得到该字符的总表达量。个体出生时缓存功能区字符频数、加权表达量和端粒总长度。

繁殖必须同时满足：

- 左右端粒总长度大于 16。
- 功能区中的 X 少于两个。
- C 的加权表达量大于 7。

### 复制与突变

- 功能区每次复制有 20% 概率突变；替换、插入、删除、倒位和重复五种操作等概率选择。
- 端粒每次复制的基础缩短概率为 90%。发生缩短时，随机选择一侧端粒，删除一个字符。
- 亲代功能区中的 P 提供保护：端粒缩短概率为 `0.9 - 0.05 × P 的加权表达量`。

突变发生在子代基因组上，亲代基因组保持不变。D、H、L、Q 的作用目前只有代码注释，尚未实现。

## 结果与人口上限

每轮开始时，如果种群列表长度达到或超过 100,000，当前 Cosmos 停止运行，计入 `Super cosmos`。人口上限按时间步检查，因此不是严格的逐个出生内存上限。

| 输出 | 含义 |
| --- | --- |
| `Random seed` | 本次实验使用的随机种子 |
| `Set rounds` | 请求运行的 Cosmos 数量 |
| `Valid cosmos` | 自然灭绝、完成运行的 Cosmos 数量 |
| `Max Gen. Observed` | 已完成 Cosmos 中最高的世代记录 |
| `Mean Max Gen.` | 各已完成 Cosmos 最高世代的平均值 |
| `Median` | 各已完成 Cosmos 最高世代的中位数 |
| `Std` | 各已完成 Cosmos 最高世代的总体标准差 |
| `Super cosmos` | 因人口上限而停止的 Cosmos 数量 |

创始个体无法繁殖的实验会输出警告并跳过。没有对应结果时，该组统计不输出。

**世代统计只包含自然灭绝的 Cosmos。** 人口超限的实验尚未观察到最终灭绝，因此只单独计数，不将其停止时的世代当作最终最高世代。超限次数较多时，不能把这组均值理解为全部实验的平均结果。

## 代码结构

- `vivificatio/anima.py`：个体、参数、基因表达、复制与突变。
- `vivificatio/cosmos.py`：单个 Cosmos 的种群演化、灭绝判断和人口上限。
- `vivificatio/main.py`：命令行参数、随机种子、多轮串行实验与结果汇总。

当前为单进程串行运行。主要模型参数在 `ANIMA_CFG` 中调整，人口上限目前写在 `cosmos.py` 中。
